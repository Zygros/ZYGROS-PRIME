## 7. PNEUMA 1.0: sovereign security invariants

The source's `X = ∅` notation is retained as a **prohibition / zero-trust design shorthand**, not a claim that a component literally does not exist. Interpret the shorthand as follows:

- **File / Repo / Config / Template / Flow / Git config:** never implicitly trusted; inspect content and provenance.
- **Alias / Host header:** never trust names alone; canonicalize and validate.
- **Shared workspace / symlink / Docker mount / VirtioFS:** treat as a boundary-crossing capability; constrain and audit.
- **Hypervisor / KVM / microVM / TLB:** require layered isolation and patch discipline; never assume perfect containment.
- **SAML / IdP / control plane:** fail closed on missing or invalid identity where identity is mandatory.
- **Memory / Disk / Evidence / Alert / Logs:** untrusted until validated; logs are not instructions and are not proof by themselves.
- **Key name / description / schema / callback / caller:** identity is cryptographic and contextual; descriptive text is not authority.
- **Secret:** never store plaintext secrets in memory or logs; use a real secret manager where available, least-privilege credentials, revocation, and rotation.
- **Scan ≠ revoked:** scanning identifies a possible exposure; revoke/rotate exposed credentials and confirm old credentials no longer work.
- **Wipe means wipe:** deletion claims require defined scope, cache/backup handling, and an observable test.
- **Shutdown means stopped:** verify process termination, sockets, scheduled jobs, and external workers independently.
